What we are building Build a private, local-first, Netflix-inspired memory website for personal use. It should feel like a premium streaming app: dark cinematic Ul, profile selection, hero banners, horizontal content rails, hover cards, modal previews, top navigation, smooth animations, and a polished admin panel. Important: Do not use Netflix trademarks, Netflix logo assets, Netflix source code, copyrighted Netflix artwork, or exact copied proprietary assets. Use original branding such as "MemoryFlix", "Randomeria", or any custom title. The visual direction can be inspired by streaming services: black/red palette, cinematic cards, profile picker, content rows, preview modal, and top nav. The user will run it locally on a personal laptop using Claude Code, with 9Router only acting as the Al routing/proxy layer. Do not design the app around 9Router; it has no effect on the website architecture. 1. Product requirements 1.1 Viewer login When the website opens, show a full-screen password page. There is no usemame. Two passwords exist: o Viewer password: logs into the normal viewing experience. o Admin password: logs into the admin panel. Correct viewer password redirects to [profiles . Correct admin password redirects to / admin Wrong password shows a clean inline error, not a browser alert. Use secure-ish local auth: o Store password hashes in . env , not plaintext in code. o Use an HTTP-only cookie containing a signed session token. o Viewer role can access viewer pages and protected media. o Admin role can access everything. 1.2 Profiles After viewer login, show a Netflix-style profile picker with exactly two initial profiles: o Randomeria o Bonus Each profile has a large avatar tile, name, hover animation, and click behavior. • Selecting a profile sets the current profile in the URL or cookie/local state and opens the streaming home page. Example route: /watch/randomeria and /watch/bonus Content should be profile-specific, so Randomeria and Bonus can have different memories, rows, storyline, chat, and book content. o 0 Book Movies TV Shows Photos Admin can enable/disable and reorder collection tabs later. • Home page shows: o Big hero section using the featured memory. o Multiple horizontal rows/categories. o Cards for photos/videos. o Hover effect with slight scale, glow, quick actions. Clicking a card opens a floating modal preview, not a separate page by default. 1.4 Memory modal behavior Each content item can be either a photo memory or video memory. For photo memory. • Show the image large in the modal. • Show title, date/label, description, tags/genre/mood. • If a music/audio file is attached, play it in a loop. • Provide play/pause button for the audio. Audio should not auto-play until the user clicks, because browsers may block autoplay. • If already user-initiated inside modal, loop playback is okay. For video memory: • Show the video inside the modal. Video loops. • Provide play/pause, mute/unmute, fullscreen controls if possible. • Show title, date/label, description, tags/genre/mood below/alongside the video. • Use poster/thumbnail image if provided. 1.5 Storyline tab Create a beautiful timeline/pathway tab showing how things started, major events, and the present. Design direction: • Desktop: cinematic winding path or center timeline with alternating cards. Mobile: vertical scroll timeline. Use large chapter cards with photo background, glassmorphism overlays, date badges, small captions, and scroll reveal animations. • Include optional event image/video, title, date, description, and mood label. Add a subtle animated line/path connecting events. Admin can create, edit, delete, and reorder story events. 1.6 Chat History tab The user will export a WhatsApp chat.
